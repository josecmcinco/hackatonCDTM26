# Inicializar un hackathon

1. Lee los archivos de `context/` y el README del repositorio.
2. Recopila el reto, criterios de evaluación, duración, tamaño y capacidades del equipo, herramientas disponibles y restricciones.
3. Identifica incógnitas críticas y pregunta por ellas antes de fijar compromisos.
4. Completa `context/PROJECT.md` con el contexto confirmado y `context/TASKS.md` con un plan inicial acotado.
5. Alinea con el equipo el stack y anota decisiones importantes en `context/DECISIONS.md`.
6. Deja `context/STATUS.md` con el objetivo inmediato, responsables si se conocen, riesgos y próximo punto de revisión.

## Resultado

El equipo comparte una definición del reto, una primera meta demostrable y una lista de próximos pasos priorizada. Separa hechos confirmados de hipótesis.
