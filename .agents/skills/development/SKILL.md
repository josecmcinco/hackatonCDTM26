# Desarrollo

1. Lee el contexto compartido y confirma la tarea prioritaria en `context/TASKS.md`.
2. Si los requisitos o contratos no están claros, resuélvelos antes de codificar.
3. Implementa el recorrido acordado siguiendo las convenciones del proyecto y evitando trabajo fuera de alcance.
4. Añade o actualiza pruebas para el comportamiento introducido y ejecuta las comprobaciones pertinentes.
5. Informa de archivos y comportamiento modificados, resultados de validación y limitaciones conocidas.
6. Actualiza `context/TASKS.md` y `context/STATUS.md`; registra en `context/DECISIONS.md` cualquier acuerdo nuevo.

## Prioridad

Mantén el producto ejecutable y demostrable. Ante una integración incierta, acuerda primero una alternativa simple con el equipo; no ocultes fallos con datos o respuestas ficticias sin señalarlos.
